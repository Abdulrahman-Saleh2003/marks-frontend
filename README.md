# ITE Damascus University Marks Portal - Web Frontend 🎓

بوابة علامات طلاب كلية الهندسة المعلوماتية - جامعة دمشق (الواجهة الأمامية / Frontend).

## 🌟 الميزات (Features)
- **واجهة مستخدم عصرية وسريعة (React 19 + Vite):** تصميم متجاوب، متناسق ومريح للعين مع الوضع المظلم والألوان الجامعية الرسمية.
- **بوابة التوثيق والأمان (Auth Gate):** تسجيل حساب برقم الهاتف، تسجيل دخول آمن، وتوليد جلسات JWT.
- **تنبيهات فورية للمشرف:** إشعار تلقائي عبر تلغرام وبريد إلكتروني عند تسجيل أي مستخدم جديد.
- **بحث ذكي وسريع:** بحث بالاسم أو الرقم الجامعي عن كافة المقررات والدرجات.
- **كشوفات رسمية وتصدير PDF:** تنزيل إشعار العلامات الفردي أو كشف المسيرة الأكاديمية الشامل بصيغة PDF معتمدة من الكلية.
- **أوائل المواد والمتفوقين:** لوحات شرف وترتيب الطلاب حسب المعدلات التراكمية ودرجات المقررات.
- **حماية شاملة ضد الاختراق:** ترويسات أمان صارمة (XSS Protection, Clickjacking Protection, No Sniff, Permissions Policy).
